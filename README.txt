Sister Birthday Wishes Website

How to use:
1. Replace music.mp3 with your own background music file.
2. Keep the file name exactly: music.mp3
3. Edit index.html if you want to change the wishes or memories.
4. Upload all files to a GitHub repository.
5. Enable GitHub Pages from repository Settings > Pages.

Files:
- index.html
- style.css
- script.js
- music.mp3 placeholder is not included. Add your own music.mp3.

Note:
Browsers block autoplay, so music starts after she taps the Start Surprise button.
